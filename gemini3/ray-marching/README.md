# Lumina Echo Demoscene

**Lumina Echo** is a self-contained, single-file HTML demoscene application featuring real-time ray-marched 3D visuals synchronized with procedurally generated audio.

## Features:
*   **Ray-marching:** Dynamic 3D scene rendered using a WebGL fragment shader.
*   **Procedural Audio:** Generates kick, bass, and lead synth sounds in real-time using the Web Audio API.
*   **Audio Reactivity:** Visual elements (object pulsing, camera roll) respond to the generated bassline.
*   **Single File:** All code (HTML, CSS, JavaScript, GLSL) is contained within `index.html`.

## How to Run:
1.  Open `index.html` in a modern web browser (e.g., Chrome, Firefox).
2.  Click the "Click to Start" overlay to begin the demoscene and enable audio playback.
